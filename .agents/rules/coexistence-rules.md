# Antigravity 共存ルール (Claude Code連携)

このプロジェクトでは、Anthropic提供のAIエージェント **Claude Code** と共存して開発を進めています。

## Claude Codeとの連携とファイル保護

- **設定ファイル・スキルの保護**:
  - プロジェクトルートの `CLAUDE.md` や、`.claude/` 以下のファイル群（Agent Skills等）はClaude Code専用の指示書です。
  - ユーザーからの明示的な指示がない限り、これらを削除・変更しないでください。
- **ファイル競合の回避**:
  - 互いの作業を妨げないよう、同一ファイルへの同時編集や意図しない上書きを避けるため、コードを変更する際は必ず現在の最新内容を確認してから編集を行ってください。

## コード・シーンへの不介入（本プロジェクト固有）

- `.agents/workflows/` 配下のワークフローは、原則として **`.gd` / `.tscn` / `project.godot` を変更しません**。
  成果物は各ワークフローが指定する置き場（例: `docs/concept/audio/`）にとどめ、ゲームへの実際の組み込みは
  Claude Code 側が精査のうえ行います。
- **RPCを変更するときの鉄則**（`CLAUDE.md` 参照）: `@rpc` が付いた関数のメソッド名・シグネチャ・
  ノードパスを変更すると、`autoload/game_manager.gd` の `PROTOCOL_VERSION` を上げないと
  旧クライアントと通信できなくなります。Antigravity 側のワークフローは現状コード変更を伴わない設計に
  していますが、将来コードに触れるワークフローを追加する場合は必ずこの鉄則を踏襲してください。

## 例外: `.gd` / `.tscn` への限定的な介入（2026-09-15〜）

上記「コード・シーンへの不介入」の原則は維持しつつ、**[/tag-ui-polish](../workflows/tag-ui-polish.md)
に紐づくタスク指示書（`.agents/workflows/tasks/*.md`）に明記された範囲に限り**、Antigravityが
`.gd` / `.tscn` を直接編集してよいことにします（Claude Codeの利用クレジットが少ない期間に、
設計判断が既に確定済み・低リスクな実装をAntigravityへ委譲するための限定的な緩和です）。

この例外下でも、以下は不変です:

- タスク指示書に列挙されたファイル**以外**は一切変更しない。
- `@rpc` が付いた関数のメソッド名・シグネチャ・ノードパス、および `PROTOCOL_VERSION` は、
  タスク指示書が明示的に許可していない限り変更しない。
- `git commit` / `git push` は行わない。作業ツリーに変更を残し、完了レポートを添えるところまで。
- 指示書に無い判断が必要になったら、実装を止めてユーザーに確認する（推測で仕様を補わない）。
