# ショップ用アート — Gemini 用プロンプト

ショップ画面を「試着しながら選ぶ」形に作り直したときの素材。生成した PNG は
このフォルダ（`tools/blender/references/`）に下記のファイル名で置く。
3D化（Blender スクリプト）と Godot への組み込みは、置かれた PNG を見て行う。

どのプロンプトにも、**画風をそろえるため次の2枚を必ず添付する**:

- `tools/blender/reference.png`（恐竜きぐるみ。質感・配色・顔の基準）
- `tools/blender/references/basketball_turnaround.png`（ターンアラウンド資料の体裁の基準）

---

## ① 店員さん（必須）→ `shopkeeper_turnaround.png`

3D化の設計図になるので、**8方向の形が互いに一致していること**が一番大事。
形がブレていたら、何度か生成し直してよいものを選ぶ。

```
添付1枚目のキャラクターと同じ世界観・同じ質感（パステルカラー、つやのあるソフトビニール風の3D、
豆型のちびキャラ、白い丸い顔に黒い点の目と小さな口）で、きせかえショップの「店員さん」の
新しいキャラクターをデザインしてください。
添付2枚目と同じレイアウトの「ターンアラウンド資料」として出力してください。

【体型】添付1枚目と完全に同じ豆型・同じ頭身。顔は白い楕円で、きぐるみのフードの丸い穴から見える。
手足は短く丸い。手は指のない丸いミトン形。

【衣装】
- 白〜クリーム色のネコのきぐるみ（頭に三角のネコ耳、内耳はコーラルピンク、お尻に短く丸いしっぽ）
- その上にミントグリーンの胸当てエプロン（肩ひもと腰ひも、お腹に大きな前ポケット1つ）
- 首からコーラルピンクのメジャー（巻き尺）を左右に垂らしている
- エプロンの胸に小さな丸い名札（文字は入れない）
- 足はきぐるみと同じクリーム色の丸い足

【配色】クリーム白・ミントグリーン・コーラルピンクの3色を中心に、差し色に少しだけ黄色。

【レイアウト】
- 上段・下段に 8方向（0° 正面、45° 左前、90° 左側面、135° 左後、180° 背面、225° 右後、
  270° 右側面、315° 右前）。全方向で同じ大きさ・同じ足の位置。
- 左端に「頭の高さ」「肩の高さ」「腰の高さ」「足の裏の高さ」の水平ガイド線。
- ポーズは全方向とも同じ、腕を体から少し離して下げた A ポーズ。表情はにっこり。
- 一番下の段に衣装ディテールのクローズアップ 4つ（ネコ耳、エプロンの前ポケット、名札とメジャー、しっぽの付け根）。
- 背景は白、影はごく薄く。見出しは「ショップ店員｜ターンアラウンド」だけ。キャラクターに文字を重ねない。
- 横長 3:2。
```

## ② 店内の奥の壁（必須）→ `shop_backdrop.png`

3D の舞台の一番奥に「書き割り」として貼る。手前の床・レジカウンター・店員さん・
プレイヤーは 3D で置くので、**絵の中には描かせない**のがポイント。

```
添付1枚目と同じ世界観・同じ質感（パステルカラー、つやのあるソフトビニール風の3D、やわらかい光）で、
かわいい「きせかえショップ（ブティック）」の店内の、奥の壁だけを描いてください。

【構図】
- 壁を真正面から見た、まっすぐな構図（パースはほとんど付けない）。カメラの高さは人の胸くらい。
- 画面の下 1/5 くらいに床が少し見え、床と壁の境目は水平な一直線。
- 画面の中央は、キャラクターが手前に立つので、ごちゃごちゃさせず落ち着いた壁面にする。

【壁にあるもの】
- 左側: 帽子を並べた棚（パーティハット、キャップ、プロペラ帽、魔法使いの帽子、王冠、ネコミミビーニー）
- 右側: カラフルな恐竜きぐるみが掛かったハンガーラック
- 中央の少し上: 大きな丸い窓（外は明るい空）
- 天井近く: 三角の旗のガーランド
- 小さな観葉植物、壁の棚に小物を少し

【禁止】人物・キャラクター・店員・レジカウンター・文字・ロゴ・看板の文字。全体にピントを合わせ、ぼかさない。

【サイズ】横長 16:9（1920×1080 相当）。
```

## ③ レジカウンター（任意）→ `shop_counter.png`

無くても形は作れるが、あると店員さんと同じ絵柄でそろえやすい。

```
添付1枚目と同じ世界観・同じ質感で、きせかえショップのレジカウンターを1つだけ描いてください。
- 角の丸い、腰くらいの高さの木のカウンター（ミントグリーンとクリーム色の塗り分け、前面にネコの足あとの模様）
- カウンターの上にレトロなかわいいレジ、小さなベル、ジェム（青い宝石）が入った小さなガラス瓶
- 正面と斜め45°の2方向を並べる。背景は白、影はごく薄く。文字・ロゴなし。横長 3:2。
```
