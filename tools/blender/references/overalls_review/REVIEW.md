# オーバーオール制作・検証メモ

基準: `../overalls_turnaround_v1.png`。既存の `fallguy.blend` を複製して衣装を制作し、Godotの着せ替えに保存ID 3として追加。既存の0〜2の衣装は維持する。

## 確認用ファイル

- `reference_comparison.png`: 正面・側面・背面の資料と実モデルの比較。背景や照明の違いを加工して隠していない。
- `godot_turnaround.png`: 周囲8方向と上面・下面。
- `pose_audit_0.png`〜`pose_audit_2.png`: 全15クリップの15%・50%・85%の姿勢。中央列は背面寄りから確認。
- `structural_validation.json`: 元モデルとの構造比較結果。
- Blender編集元: `../../overalls.blend`
- Godotモデル: `../../../../assets/character/outfits/overalls.glb`
- 試着シーン: `../../../../tests/overalls_preview.tscn`

## 修正した点

1. 半袖、胸当て、肩ひも、胸ポケット、後ろポケット、留め具、折り返し裾、しっぽ用開口を制作。
2. 肩ひもの帯幅を経路に対して直角に取り、横から細い線に見える形を修正。
3. 腰と股下のウェイトを見直し、左右の縫い合わせの引き裂けとシャツの露出を修正。
4. 胸当てと短パンを溶接し、一続きの布として腰の段差を抑制。
5. 胸当てを下げ、留め具とポケットを拡大。留め具を外側へ移し、前側のひもを資料の縦に近い形へ調整。
6. デニムを落ち着いた青へ調整。128pxの織り目テクスチャをGLBに含める。シャツは影の中でもクリーム色が残る弱い発光を使用。
7. 布の分割数を減らし、初期高密度版の約17.4万三角形から約9.2万三角形へ削減。顔や元のしっぽの形状は簡略化しない。

改訂画像と当時の形状コードは `../../preview/overalls/revision01`〜`revision06` に保存してある。確認用の中間画像フォルダはGit管理対象外。

## 検証

- 元のしっぽの連結成分98頂点、顔1282頂点、16本のレスト骨格を比較して一致。
- 元キャラのウェイトを保持。新しい衣装の表示面のウェイト合計を検証。
- 15クリップを保持。Godotで45時点を描画し、骨の変換に非有限値がないことを検証。
- `tests/costume_model.tscn`: 既存衣装の番号、アニメーション、固定配色の回帰確認。
- `tests/costume_screen.tscn`: オーバーオールのカード表示、選択、3Dプレビュー、色変更無効・帽子変更有効を確認。テストから実プロフィールは保存しない。
- `git diff --check`: 空白エラーなし。

## 資料との差と確認の限界

### 2026-09-29 脚が透けて見える問題の修正

- 原因は透過材質ではなく、衣装下の体表削除が裾付近の脚の面に及んでいたこと。修正前は元の両脚288面のうち112面が欠けていた。
- 両脚の連結成分を削除対象から除外。全288面の形状と元ウェイトを保持し、服の形・配色・体型は変更しない。
- `verify_overalls.py` に面単位の保持検証を追加。修正前の資産で失敗、再生成した資産で通過することを確認。
- Godotで静止10方向と15アニメ・45姿勢を再撮影して確認。ログは `../../preview/overalls/leg_regression_before.log`、`leg_regression_after.log`、`render_leg_fix_console.log`。

- 元の恐竜モデルを優先しているため、生成資料より顔の立体的な縁取りが厚く、体型・足の長さ・背びれの大きさに差がある。衣装に合わせて元の骨格や顔を変えていない。
- 上面・下面は実際の3Dから撮影した形を採用。生成画像の全方向が厳密に整合しているとはみなしていない。
- しっぽ周辺の後ろポケット・交差部分は、実モデルの背びれと開口の位置に合わせている。背びれはひもの上に見える。
- 本編の照明では資料の柔らかいスタジオ光より陰影が強い。画像のピクセル単位の一致や、全フレーム・全カメラ位置での貫通ゼロを保証する検証ではない。
- 布は骨による変形で、布シミュレーションは使用しない。多人数同時表示時のFPS測定・オンライン対戦試験は今回の検証に含めていない。
- Godot実行時に環境由来の証明書・シェーダーキャッシュ・エディタ設定保存のエラーがログに出る場合がある。各検証の成功マーカーとは区別している。

## 再現方法

1. Blenderをバックグラウンド起動し `tools/blender/build_overalls.py` を実行。
2. `tools/blender/verify_overalls.py` で構造を検証。
3. Godotでインポート後、`tests/overalls_preview.tscn -- outfit-shots pose-audit` を通常レンダラーで実行。
4. `tools/blender/assemble_overalls_review.ps1` と `tools/blender/assemble_overalls_turnaround.ps1` で一覧を生成。

Blender、GLB、比較画像を成果物として提出する。最終的な見た目の好みはユーザー確認の対象とし、技術検証の成功だけで「資料と完全一致」とは判定しない。
