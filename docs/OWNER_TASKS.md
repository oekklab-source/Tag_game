### A-2. Stripe を本番モードに切り替える

- **なぜ**: 現在の Price ID と API キーはテストモード（[DEPLOYMENT_CHECKLIST.md](DEPLOYMENT_CHECKLIST.md) §2）。
  このまま公開するとテストカードでしか買えず、売上にならない。
- **前提**: A-1（特商法の表記が先。表示価格と Stripe の実値を一致させるため）。
- **手順**: [service/commerce-api/README.md](../service/commerce-api/README.md) の「本番切替時は…」の項。要点は:
  1. Stripe の本番モードで3商品（300 / 800 / 2000 ジェム）の Product/Price を作り直す。
  2. 新しい Price ID を [autoload/currency_pack_catalog.gd](../autoload/currency_pack_catalog.gd) と
     [service/commerce-api/src/index.ts](../service/commerce-api/src/index.ts) の `PACKS` の2箇所に反映する（← Claude に頼める）。
  3. `npx wrangler secret put STRIPE_SECRET_KEY` で `sk_live_...` を入れる。
  4. Stripe Dashboard（本番モード）で Webhook を登録し直し、`STRIPE_WEBHOOK_SECRET` も入れ直す。
  5. `npx wrangler deploy` → クライアントを再ビルドして配布。
- **完了条件**: 本番カードで最小パックを1回買い、ジェムが付与され、Stripe の本番ダッシュボードに記録が出る
  （確認後に自分で返金してよい）。

## C. 実機確認

### C-1. スマホのブラウザでのタッチ操作（C-07 T-8-d）

開発機にはタッチ画面もブラウザ自動化ツールも無いので、確認できていない。
Web 版のデプロイ後、**iOS Safari と Android Chrome の両方**で次の項目を見る。

> 2026-09-30: Android Chrome で試した結果（ボタンが小さい・ダッシュしながら視点を回せない・
> ボタンを同時に押せない・全画面にしたい）を受けて、ボタンの大きさ・配置・ダッシュ・全画面を作り直した
> （README「スマホ（タッチ操作）」節）。下の 4〜9 はその作り直した部分の確認。

1. **縦持ち警告**: 縦持ちでゲームの URL を開くと「横向きにしてください」が出る。横にすると消える。
2. **リンクのプレビュー**: ゲームの URL を LINE と Discord に貼ると、タイトル・説明・画像のカードが出る。
   出ないときは、まず `https://oekklab-source.github.io/Tag_game/og_image.png` が開けるかを見る。
3. **タッチ操作の「自動」**: 設定のタッチ操作を「自動」にすると、スマホではタッチ UI が出て、PC のブラウザでは出ない。
4. **ボタンの大きさ**: 右下のボタン4つとスティックが、見ないでも押せる大きさか。
   小さい・大きい・位置が合わないなら、どのボタンがどちら向きにずれているかを伝える。
5. **同時操作**: 左手で移動しながら、右手でダッシュを1回タップ（ON）→ そのまま視点を回す → ダイブ、が全部効く。
   左手の指は左下のどこに置いても動ける。「カモン」の長押しで挑発メニューが出て、指を離した位置のものが選ばれる。
6. **ダッシュの自動 OFF**: スタミナが切れたとき・左手を離したとき・≡でポーズしたときに、ダッシュが OFF（ボタンの色が戻る）になる。
7. **視点ドラッグの速さ**: 速すぎたり遅すぎたりしないか（今はマウス感度をそのまま使っている。
   合わなければタッチ専用の感度を足すので、どちら向きにずれているかを伝える）。
8. **全画面（Android）**: タイトル画面か試合中の左上の「全画面」で全画面になり、横向きに固定される。「全画面を解除」で戻る。
9. **全画面（iPhone）**:
   - Safari で開いたとき、ボタンやタイマーがノッチ・角の丸みに隠れない。
   - タイトル画面の「全画面」で「ホーム画面に追加」の案内が出る。
   - 追加したアイコンから起動すると、アドレスバー無しで表示される。
   - そのとき上部に「招待リンクを貼り付けて参加」が出る。招待リンクをコピーしてから押すと参加できる
     （貼り付けの確認が出たら「ペースト」を押す。読めなかったときは入力欄が出るので、そこに貼る）。
   - 名前を入れる欄をタップしたときにキーボードが出るか（出ないなら伝える。ホーム画面版は名前を設定し直す必要がある）。
10. **ポーズ中**: ≡ボタンでポーズを開いている間、裏でキャラが動かない。

- **終わったら**: ダメだった番号と機種・ブラウザを伝える。
