## 3. 収集する情報

### 3.1 EOS Connect経由の識別子・プロフィール情報

本ゲームはオンライン対戦のため、Epic Online Services (EOS) の Connect 機能(匿名の
Device ID認証、Epicアカウントへのログインは行わない)を利用してプレイヤーを識別します。

収集・保存する情報:

- EOS上の匿名プレイヤー識別子(Product User ID)
- プレイヤー表示名
- 対戦成績(レート、対戦回数、鬼側/逃走側それぞれの勝利数、最高レート)
- 所持アイテム(コスチューム・帽子)の状態
- ジェム残高(ゲーム内仮想通貨)

保存場所: 端末ローカル(`user://profile.json`、[autoload/profile_manager.gd](../autoload/profile_manager.gd)
参照)、およびEOS Player Data Storage(クラウド同期、
[autoload/eos_manager.gd](../autoload/eos_manager.gd) 参照)。

### 3.2 フレンド機能に関する情報(自社サーバー保存)

フレンド機能を利用する場合、以下の情報が当社が運用するサーバー(Cloudflare Workers上の
`friend-api`)に保存されます。認証は EOS Connect が発行する ID Token(JWT)を用います。

- プレイヤー表示名
- 自己申告の対戦成績・レート・着用スキン
- オンライン在席状況(ハートビート)
- フレンド関係(フレンドコードによる申請・承認)

(参照: [autoload/friend_backend_client.gd](../autoload/friend_backend_client.gd)、
[docs/SECURITY_NOTES.md](SECURITY_NOTES.md) 5〜6章)

### 3.3 決済情報(Stripe)

ジェムの購入には [Stripe, Inc.](https://stripe.com/) の Stripe Checkout を利用します。
決済はシステムブラウザ上のStripeホスト型決済ページで行われ、**クレジットカード番号等の
決済情報は、ゲームクライアントおよび当社サーバーのいずれにも一切保存されません**。決済の
成立確認は Stripe からのWebhook通知のみを正とし、当社サーバー(`commerce-api`)がこれを
検証します。

端末ローカルには、購入処理中の一時的な状態(注文ID・購入パックID・作成時刻のみ)を
`user://pending_purchase.json` に保存します。
(参照: [autoload/stripe_purchase_provider.gd](../autoload/stripe_purchase_provider.gd))

### 3.4 マルチプレイ接続情報

オンライン対戦のホストを行う場合、他プレイヤーが参加できるよう、接続用トンネルの
ホスト名・アドレスがEOSロビーの属性として一時的に公開されます(対戦成立後、当該情報は
ロビーの解散とともに失効します)。
(参照: [autoload/eos_manager.gd](../autoload/eos_manager.gd) 223〜234行目)

### 3.5 レーティング・対戦記録(自社サーバー保存)

オンライン対戦(EOSロビー経由のレート戦)の結果は、当社が運用するサーバー(Cloudflare Workers上の
`rating-api`、データベースは Cloudflare D1)に送られ、レートの計算と保存はサーバー側で行います。
認証は 3.2 と同じく EOS Connect の ID Token を用います。

- EOS上の匿名プレイヤー識別子(Product User ID)ごとの、レート・対戦回数・鬼側/逃走側の勝利数・
  最高レート・最終更新時刻
- 1試合ごとの記録: 試合ID、報告したプレイヤーの識別子、参加者全員の識別子と試合前後のレート・
  増減・ランク名、記録時刻(二重計上の防止と、問い合わせ時の確認に使う)
- 切断によるレートの減点の記録(上と同じ形式)

ランキング表示のため、レート上位のプレイヤーの**識別子・レート・対戦回数**は、認証なしで
取得できる形で公開されます(`/leaderboard-top`)。
(参照: [service/rating-api/schema.sql](../service/rating-api/schema.sql)、
[service/rating-api/src/index.ts](../service/rating-api/src/index.ts))

### 3.6 IPアドレス

本ゲームは、次の場面で利用者の IP アドレスを第三者(主に Cloudflare, Inc.)に送ります。

- **当社サーバーとの通信**: フレンド機能・決済・レーティングのサーバー(いずれも Cloudflare Workers)は、
  通信の性質上、接続元の IP アドレスを受け取ります。当社はこれを**回数制限(不正な大量リクエストの防止)
  だけに使い**、IP アドレスと日付を組み合わせたカウンタとして約48時間保存します
  (レーティングのサーバーでは、期限切れのカウンタを後から順次削除するため、48時間を過ぎても
  しばらく残ることがあります)。
- **インターネット越しの対戦(ホストする側・参加する側とも)**: ホストの PC は Cloudflare のトンネル
  (cloudflared)を通じて公開され、参加者はホストに直接ではなく Cloudflare を経由して接続します。
  このため、ホスト・参加者双方の IP アドレスと対戦中の通信は Cloudflare を経由します。
- **EOS のロビーの接続先**: ロビーを作った直後、トンネルができるまでの間(トンネルを張れなかった
  場合はロビーがある間ずっと)、ホストの**同一ネットワーク内のアドレス(通常はプライベート IP アドレス)**が
  接続先としてロビーに公開されます(3.4)。
- **同じネットワーク内での直接対戦**: アドレス(IP)を入力して接続する場合、対戦相手同士で
  IP アドレスが互いに分かります。
- **ブラウザ版**: ブラウザ版のゲームは GitHub Pages(GitHub, Inc.)から配信されるため、
  ブラウザ版を開くと GitHub に IP アドレスが送られます。

(参照: 各サービスの `CF-Connecting-IP` を使う回数制限、[autoload/network_manager.gd](../autoload/network_manager.gd)
の `_launch_tunnel()`、[autoload/eos_manager.gd](../autoload/eos_manager.gd) の host_addr の扱い)

### 3.7 ログファイル(端末内のみ)

Windows 版は、動作の記録(ログ)を端末内の `%APPDATA%\TagGame\logs\`(`user://logs/godot.log`。
直近5回分)に書き出します。ログには、エラーの内容のほか、**自分の Product User ID** や、
エラーの内容によってはフレンドの識別子が含まれます。

ログは**当社に自動で送信されることはありません**。不具合のお問い合わせの際に、調査のため
ログファイルの提出をお願いすることがあります。その場合、提出は任意で、提出いただいたログは
その不具合の調査だけに使い、調査が終わったら `[削除までの期間を記入]` 以内に削除します。

### 3.8 収集しない情報

本ゲームは、氏名・住所・電話番号・生年月日等の実個人を特定する情報を直接収集しません。
決済に伴うこれらの情報の取り扱いは、Stripeのプライバシーポリシーに従います。

## 付録B: オーナー判断が要る論点(GDPR・データ処理契約など、2026-10-16 KAN-16)

事実の整理と論点だけを書く。**どれも法的助言ではない**ので、結論は専門家の確認を経て決めること。

### B-1. EU 居住者に提供するか(GDPR が適用されるか)

- itch.io の配信は国を限定しないので、EU の利用者も入手できる。EU の利用者に向けて提供する事業者には、
  EU 外の事業者でも GDPR が適用されうる(GDPR 第3条2項)
- 本ゲームが扱う **Product User ID・IP アドレス・表示名・対戦記録**は、GDPR 上の個人データにあたりうる
- 適用される場合に要りそうなもの(専門家に確認する項目):
  - 処理の法的根拠(ゲームの提供=契約の履行、不正防止=正当な利益 など)の明記
  - 開示・削除の請求への対応手段。**削除は EOS Player Data Storage・friend-api(KV)・rating-api(D1)の3か所に
    データがある**ので、どこまで消せるか・誰が手で消すかを決める必要がある(第10条)
  - EU 域内代理人の選任(第27条。例外の要件に当たるかの確認)
  - 保存期間の明記(第4条のプレースホルダ)

### B-2. 処理を任せている事業者との契約(DPA)

| 相手 | 扱うデータ | 確認すること |
|---|---|---|
| Epic Games(EOS) | Product User ID、Player Data Storage のプロフィール | Developer Agreement 第11条は、EU データ主体の個人データを含む場合に、標準契約条項を含む DPA の締結を求めうるとしている([EOS_LEGAL_REVIEW.md](EOS_LEGAL_REVIEW.md) 第3章)。Developer Portal で DPA を結ぶ手続きがあるか、オーナーが確認する |
| Cloudflare | サーバーのデータ(D1/KV)、IP アドレス、トンネルの通信 | Cloudflare の DPA が利用規約に組み込まれているか(別途の締結が要るか) |
| Stripe | 決済情報 | Stripe の DPA が利用規約に組み込まれているか |

### B-3. 日本の個人情報保護法との関係(関連)

- Epic・Cloudflare・GitHub・Stripe はいずれも外国の事業者。個人情報(他の情報と照合して個人を識別できるもの)を
  渡す場合は「外国にある第三者への提供」(第28条)の要件(本人の同意、または相手方の体制の確認と情報提供)
  に当たるかを確認する
- Product User ID・IP アドレスが個人情報・個人関連情報のどちらに当たるかで要件が変わる

### B-4. 実装に関わる判断

- **公開ランキングに Product User ID が出る**(3.5)。表示名に置き換える・ハッシュにするなど、
  公開する情報を減らすか
- レーティング・対戦記録を**無期限に保存している**。期限を決めるなら、削除の仕組み(定期実行など)が要る
- 3.7 のとおり、ログには Product User ID が残る。提出をお願いする運用にするなら、扱いをポリシーに書く(案は 3.7)
