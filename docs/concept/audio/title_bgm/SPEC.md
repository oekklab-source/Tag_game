# タイトル/ロビー BGM 作曲仕様書

## 概要
ゲーム起動直後のタイトル画面および、ホストが部屋を立てて他のプレイヤーを待っている「ロビー」画面で流れるBGMです。

## 使用シーン
- `scenes/title.tscn` 起動時
- 待機中（なかま待ち、きせかえ、ショップ画面、フレンド画面など）

## 想定ムード
- ポップで明るい、ワクワクするような雰囲気。
- マリオ風のカラフルでポップな世界観（160x160mの段丘状のマップ、空に浮かぶ島、虹色のダッシュパネルなど）に合致する、軽快でキャッチーな曲調。
- これから「オンライン鬼ごっこ」が始まるという期待感を高めつつ、待機中に長く聴いても疲れない（主張しすぎない）バランス。

## 楽曲仕様
- **テンポ (BPM)**: 120〜130程度
- **キー**: Cメジャー または Fメジャー など、明るく開放感のあるキー
- **尺**: 30秒〜1分程度でループ
- **ループ秒数**: 0.000秒 〜 32.000秒 （※生成された最終ファイルに合わせてClaude Code側で調整してください）
- **音色イメージ**:
  - メインメロディ: シンセリードやマリンバなど、輪郭がはっきりして明るい音色。
  - バッキング: アコースティックギター、ブラスセクション、またはチップチューン系のシンセ（ゲームっぽさを出すため）。
  - リズム: 軽快な8ビートまたはハーフタイムシャッフル。

## 実装時の注意点（Claude Code 向け）
- Godotの `AudioStreamOggVorbis` の `loop` を有効にし、ループ開始・終了秒数を設定して組み込んでください。
- バスは現在のところ `Master` バス1本のみです。`AudioServer` や `AudioStreamPlayer` など再生に必要なノード・コードの追加はClaude Code側でよしなに判断してください。
- 最終的に組み込むBGMのファイル形式は `.ogg` （Ogg Vorbis）を推奨します。
- 生成した最終的な `.ogg` ファイルは `assets/` 配下などの適切なディレクトリに配置してください（`docs/concept/audio/` 配下は仕様書と参考音源の置き場です）。

## 2026-09-14 追記: レビュー反映（第2版）
前回の音源（約11秒）が短すぎたため、以下の要件を厳密に満たすように再生成・実装を行ってください。

- **厳格な尺の確保**: 必ず **30秒〜1分** の長さを確保すること。
- **楽曲展開の付与**: 単調な数小節のループではなく、「Aメロ → Bメロ → サビ（ループ戻り）」のような明確なメロディ展開を持たせること。
- **ループ構造**: 待機中ずっと流れても疲れないよう、展開の後に不自然なくループの頭に戻るような構成を意識すること。
- （BPM 120〜130、キー C/Fメジャーの明るくポップな雰囲気は前回を踏襲して構いません）

## 2026-09-14 追記: レビュー反映（第3版・プロ品質基準）
第3版のプロ品質レビュー（Web版Gemini）に基づく改善指示です。本仕様に従って、再生成・実装を行ってください。

- **ループ処理の修正**:
  リバーブやディレイの余韻（テール）が途切れて生じるクリックノイズやリズムのヨレを防ぎ、シームレスなループを作成すること。書き出し時に余韻を先頭に回り込ませる（Wrap Remainder等の機能を使用する）、あるいは2ループ分書き出して後半の1ループを切り出す手法などを採用し、ゼロクロスポイントで適切に繋がるように処理すること。
- **ミックス（EQ・サイドチェイン）の整理**:
  - キックドラムがクリアに抜けるよう、ベースとコード楽器のローミッド帯域（200〜300Hz）をEQで少しカットしスペースを作ること。
  - ベースにキックをトリガーとした軽いサイドチェインコンプをかけることで、帯域被りを防ぎつつグルーヴ感を持たせること。
  - リードシンセの高音域（3〜5kHz帯）が長時間ループ再生時に耳に痛くならないよう、ダイナミックEQなどでマイルドに抑え、聴き疲れしない音圧バランスに調整すること。
- **アレンジの拡張（尺と展開）**:
  - **尺**: 全体の尺を **45〜60秒** 程度に伸ばすこと。
  - **展開**: 「Aメロ（元気な推進力）」から「Bメロ（リズム要素を減らす、またはサブドミナントコードへ展開して浮遊感を出す）」への明確な起伏を作ること。
  - Bメロではリード楽器を休ませ、コードとリズムだけで展開するアプローチも効果的。これにより単調さをなくし、長時間の滞在でも飽きさせない構成にすること。
- **音色のレイヤリング（生楽器要素の追加）**:
  - 安っぽさを排除し、「カラフルな箱庭感」を演出するため、リードシンセにマリンバや木琴等のアタック感のあるアコースティック楽器のサンプルをレイヤーすること。
  - ドラムトラックにも電子音だけでなく、コンガやシェイカー等の生楽器系パーカッションを薄く重ねて質感を高めること。
