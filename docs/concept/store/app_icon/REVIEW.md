### 客観チェック
- 規格: 元絵は 1024x1024 の PNG。`icon.ico` は 16/32/48/64/128/256 の6サイズ（どれも 32bit、PNG 圧縮）で、
  SPEC の (b) と KAN-53 の完了条件（16/32/48/256 を含む）を満たす
- 小さいサイズ: 16/32/48 は Blender のシンボル（入れ替わりの矢印＋鬼と逃げる人）、64 以上はイラスト（KAN-82 の決定どおり）
- 組み込み先: `project.godot` の `config/icon="res://icon.png"`（512x512）と `config/windows_native_icon="res://icon.ico"`。
  Web 版は `web/apple-touch-icon.png`（180、角を透明にしない）・`icon-192.png`・`icon-512.png`（`icon.png` と同じファイル）を
  `manifest.webmanifest` と `export_presets.cfg` の `apple-touch-icon` 行から参照し、`.github/workflows/web-build.yml` が配信物へコピーする
- exe への反映: `tools/export_windows.ps1` で書き出した `ReverseTag.exe` のアイコン資源（RT_GROUP_ICON 1つ・RT_ICON 6つ）を
  取り出し、`icon.ico` の6サイズとバイト単位で一致することを確かめた（2026-11-10）
- 他社の意匠: 他社のロゴ・画面は使っていない。右上のカラフルなキャラについては「注意」

### 主観チェック
- 256・64: 青いきょうりゅうが走っている絵だと分かる。64 は背景がにぎやかだが、主役の青は埋もれない
- 48・32: シンボルの赤と緑の矢印が輪になっているのが分かる。紺の角丸なので、明るい背景でも暗いタスクバーでも縁が見える
- 16: カラーなら「紺の角丸に赤と緑」として他のアプリと見分けられる。矢印の形までは読めない
- 大きいサイズ（イラスト）と小さいサイズ（シンボル）で見た目が大きく変わる。エクスプローラーの表示の大きさを変えると
  別のアイコンに見えるが、細かい絵を 16〜48px に縮めると潰れるので、KAN-82 でこの組み合わせに決めた

### SPEC との差分
- 「形」「配色」（2本の矢印の輪・黄色の背景・ベタ塗り）は KAN-82 で採用しなかった。元絵はグラデーションと影のある生成イラスト
- 視認性の要件（16x16 でシルエットが判別でき、グレースケールでも形が分かる）は、**16px のグレースケールだけ満たさない**。
  赤と緑の明るさが近く、色を抜くと矢印が背景の紺と混ざる。32px 以上のグレースケールは輪郭が残る
- 「REVIEW.md が PASS になるまで組み込まない」という順序は守れていない（SPEC.md の 2026-11-10 追記）

### 注意
- 16px のグレースケールは、色覚の多様性への配慮としては弱い。直すなら、シンボルの矢印の片方を明るく（または縁取りを太く）して
  明るさの差をつける。ゲームの見た目には影響しないので、リリース後に回してもよい
- 右上のカラフルなキャラが Fall Guys に似ている点は、KAN-18・KAN-48 の専門家への確認の結果に従う。結果次第でアイコンも作り直す
- 生成に使ったツールとプロンプトは KAN-82 で記録待ち（`docs/AI_GENERATED_ASSETS.md` は「ツール名の記録なし」のまま）
