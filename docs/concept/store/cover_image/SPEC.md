# カバー画像 制作仕様書

## 概要
itch.ioのストアページ・一覧・SNS共有カードに使われるカバー画像。

## 規格
- **630 x 500px 推奨**(itch.io仕様。最小315x250、比率315:250固定)
- PNG、静止画(アニメGIFも可だが今回は静止画に限定)

## 構図
鬼(赤)と逃走者(緑)の**非対称な対比**を主題にする。「見えている側/見えていない側」
「追う側/隠れる側」という本作の核心ルール([README.md](../../../README.md)の
「## ルール」参照)が一目で伝わる構図が望ましい。
マップの雰囲気はカラフル・ポップ(160×160mの段丘状マップ、ゾーンごとのテーマ色、
滑り台・マンホール・ダッシュパネル等のギミック。詳細は README.md の「## マップ」
「## ギミック」参照)。

## 配色(正本、2026-10-30 アイコンに合わせて変更)
[app_icon/SPEC.md](../app_icon/SPEC.md)(2026-10-27 変更)と揃え、ストア一覧で同じゲームだと分かるようにする:

- 逃走者: `#22c55e`(緑)
- 鬼: `#ef4444`(赤)
- アクセント: `#facc15`(黄)
- 背景(マップ): ゾーンのテーマ色(黄緑・水色・紫・ピンク)を使ったカラフルな配色。紺一色にはしない

以前は [icon.svg](../../../icon.svg) 由来の紺`#2b3a67`の背景だった。

## 文字の扱い(重要)
正式タイトルは「Reverse Tag!」(日本語題「逆転鬼ごっこ」、2026-10-25 KAN-50)に決まったが、
画像生成ツールは文字を崩しやすいので、**生成の段階では文字を焼き込まない**。文字なしで成立する構図にし、
タイトル入りの版が要るときは、文字なしの画像に画像編集ソフトでロゴ文字を重ねて作る。
生成用のプロンプトは [PROMPT.md](PROMPT.md)。

## 禁止事項
実装や既存資料に無い要素を描かない(銃器・車両・ホラー調の夜景など)。
このゲームは非対称の鬼ごっこであり、戦闘・暴力表現は含まない。

## 出力先とレビューゲート
生成物は`docs/concept/store/cover_image/`配下に置く。`REVIEW.md`でPASSと判定されるまで、
Claude Codeはこの画像をitch.ioへのアップロード手順に載せない。
