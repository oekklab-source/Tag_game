# カバー画像 制作仕様書

## 概要
itch.ioのストアページ・一覧・SNS共有カードに使われるカバー画像。

## 規格
- **630 x 500px 推奨**(itch.io仕様。最小315x250、比率315:250固定)
- PNG、静止画(アニメGIFも可だが今回は静止画に限定)

## 構図
鬼(赤)と逃走者(緑)の**非対称な対比**を主題にする。「見えている側/見えていない側」
「追う側/隠れる側」という本作の核心ルール([README.md](../../../README.md)の
「## ルール」参照)が一目で伝わる構図が望ましい。
マップの雰囲気はマリオ風のカラフル・ポップ(160×160mの段丘状マップ、ゾーンごとのテーマ色、
滑り台・マンホール・ダッシュパネル等のギミック。詳細は README.md の「## マップ」
「## ギミック」参照)。

## 配色(正本)
[icon.svg](../../../icon.svg)の実ファイルから確定した既存の記号を踏襲する:

- 背景: `#2b3a67`(紺)
- 逃走者: `#4ade80`(緑)
- 鬼: `#ef4444`(赤)
- 連結線・アクセント: `#ffffff`(白)

## 文字の扱い(重要)
仮タイトル「3D Chase Game」は`project.godot`上の暫定名称で確定名ではないため、
**画像に文字として焼き込まない**。文字なしで成立する構図にすること。
正式タイトル確定後、文字入り版を別途作成する(`tag-game-ux-fix-roadmap.md`のPhase 5
「ユーザーのみが行える操作」I5-6参照)。

## 禁止事項
実装や既存資料に無い要素を描かない(銃器・車両・ホラー調の夜景など)。
このゲームは非対称の鬼ごっこであり、戦闘・暴力表現は含まない。

## 出力先とレビューゲート
生成物は`docs/concept/store/cover_image/`配下に置く。`REVIEW.md`でPASSと判定されるまで、
Claude Codeはこの画像をitch.ioへのアップロード手順に載せない。
