## 2026-11-10 レビュー（v2 の4案、KAN-87）

**判定**: 4案とも PASS（どれを採用してもアップロードしてよい。どれにするかはハマちゃんが決める）

対象: `cover_v2a_close_call.png`・`cover_v2b_reverse.png`・`cover_v2c_playground.png`・`cover_v2d_team_up.png`
（作り方とコンセプトは [CONCEPTS.md](CONCEPTS.md)、並べた一覧は `cover_v2_sheet.png`）

### 客観チェック（4案共通）
- 規格: どれも 630x500 の PNG 静止画。比率 1.26（315:250）
- 文字: どれも「REVERSE TAG!」だけ（英語のみ）。書体・色・ふち取りはタイトル画面のロゴと同じ作り方
- キャラ: どれもゲーム内のきょうりゅうのモデル（`tools/blender/fallguy.blend`）。小物もゲームの `.blend` から読み込んだ
- 禁止事項: 銃器・車両・暴力表現・夜景は無い。ダイブは「鬼が捕まえるために飛び込む」ゲームの動き（README の「ダイブ」）で、攻撃ではない
- 他社の意匠: 他社のキャラ・ロゴ・画面は使っていない。参考にした12作品はカバーの構図の原則だけを見た（CONCEPTS.md の表）

### 配色の実測（5x5 画素の平均）
光を当てた立体なので SPEC の値とは完全には一致しないが、どれも同じ色相に見える。

| 案 | 実測 |
|---|---|
| A | 緑 `#33c463`・赤 `#c55454`（陰の面）・空 `#68cdfa`・芝 `#a5e34e` |
| B | 赤 `#ff5b5b`・緑 `#3be373`・地 `#9bf2ba` / `#fdb4b4` |
| C | 緑 `#38a358`（陰の面）・赤 `#e74d4d`・ゾーン `#44bdf6` / `#a289ef` / `#ffb8e4`・芝 `#a5e542` |
| D | 青チーム `#72bbff`・橙チーム `#ffbd48`（どちらも光の当たる面）・幽霊 `#daf9f8`・地 `#feeb76` |

背景はどれも紺一色ではない（SPEC）。D だけは役割の赤と緑ではなく、ゲームの Reverse Tag モードのチーム色（`TEAM_COLORS`）を使っている。

### 主観チェック
- A: 逃げる緑と飛びつく赤が大きく、何のゲームか一目で分かる。緑の顔は前かがみで少し隠れる
- B: 形が単純で、315x250 に縮めてもいちばん読める。アイコンと同じ「入れ替わりの矢印」なので、一覧でアイコンと並んだときにつながる
- C: マップの楽しさは出ているが、315x250 では緑のキャラが小さく見つけにくい
- D: 大人数で遊べることと着せ替えが伝わる。315x250 では帽子と幽霊が見分けにくい

### 注意
- キャラの意匠が他社に近くないかは KAN-48 の専門家への相談の結果に従う。結果次第でこの4案も作り直す（v1 と同じ）
