# 法務3文書の専門家レビュー 依頼文と確認事項(KAN-18)

法務3文書(特定商取引法に基づく表記・EULA・プライバシーポリシー)を専門家に見てもらうための依頼文と、
確認してほしい論点の一覧。依頼文はそのままメールに貼れる形にしてある。論点は、これまでのオーナー判断
(Jira の KAN-14・15・17・48・62)で「専門家に確認する」とした点を1か所に集めたもの。

依頼先の候補は、ゲーム・IT・個人情報保護に詳しい弁護士(オンラインゲームの利用規約・特商法の表記の
レビュー実績があるところ)。GDPR(論点6)は、EU 対応の経験がある事務所かどうかも確認するとよい。

## 別紙: 確認事項(依頼文と一緒に送る)

1. **特商法: 所在地・電話番号の省略**(KAN-14)
   個人で販売するため、所在地と電話番号を「ご請求があった場合には遅滞なく開示いたします」と書いて省略したい。
   この形で省略できるか。省略する場合に、表記や請求時の運用で必要なことは何か。
2. **ジェムと資金決済法**(KAN-15)
   ジェムは有効期限なしの前払い通貨。自家型の前払式支払手段にあたるとして、未使用残高が基準日に1,000万円を
   超えない規模なら届出は不要と整理してよいか。その場合でも表示すべき事項があるか。
   (ジェムで買った見た目アイテムをフレンドに贈るギフト機能があるが、ジェム自体の譲渡や換金はできない)
3. **総額表示と返金**(KAN-15)
   ジェムの価格は Stripe の実請求額をそのまま「税込」と表示する。返金は原則不可とし、当方の不具合のときと、
   未成年者が保護者の同意なく購入し保護者から取消の申し出があったときは返金する。この書き方で足りるか。
4. **未成年者の利用**(KAN-17)
   年齢制限は設けず、未成年は保護者の同意を得て利用・購入するよう求める形にした。年齢確認はしていない。
   この方針と EULA・プライバシーポリシーの文言で問題ないか。
5. **準拠法・管轄**(KAN-17、EULA 第10条)
   日本法・東京地方裁判所を専属的合意管轄とした。消費者(海外の利用者を含む)との契約でこの条項が有効か。
   書き方を変えるべきか。
6. **GDPR**(KAN-17、プライバシーポリシー第7章・付録B-1)
   EU の利用者にも提供する。プライバシーポリシーに書いた法的根拠(契約の履行・正当な利益)と EU の利用者の権利の
   書き方で足りるか。EU 域内代理人(GDPR 第27条)の選任が必要か。削除請求はメールで受け付け、3か所のサーバーの
   データを手作業で消す運用で足りるか。
7. **外部の事業者とのデータ処理契約・外国にある第三者への提供**(付録B-2・B-3)
   Epic Games(EOS)・Cloudflare・Stripe・GitHub に処理を任せている。各社とデータ処理契約(DPA)を別途結ぶ必要があるか。
   個人情報保護法第28条(外国にある第三者への提供)の対応として、ポリシーに追記すべきことはあるか。
8. **itch.io の代金回収と表示義務**(KAN-62)
   本体の投げ銭は itch.io が代金を回収する方式(Payouts)にした。本体分について、特商法の表示義務が誰にあるか。
   ジェム(自社 Stripe 決済)の表記と分けて書く必要があるか。

あわせて、キャラクターの見た目と、ゲーム内の「？ブロック」の意匠が他社のゲームに近すぎないかも相談したい
(KAN-48)。法務3文書とは別件なので、依頼先が対応できるか先に聞く。
