# 3D Chase Game 起動・マルチプレイマッチング手順書

本ゲーム（3D Chase Game）の起動方法、および友達と一緒にマッチングして動作確認を行うための詳細手順書です。

---

## 📌 マッチング方式の選択

環境や友達の状況に合わせて、以下のいずれかの方法を選択してください。

| 方式 | おすすめ用途 | ホスト環境 | 友達（参加者）環境 | 特徴 |
| :--- | :--- | :--- | :--- | :--- |
| **① Steam P2Pマッチング** | PC同士で本格的に対戦・レート検証したい場合 | PC (Windows) + Steam | PC (Windows) + Steam | ゲーム内ロビー一覧・おまかせマッチで自動合流 |
| **② 参加リンク共有（Web/PC）** | 友達にソフトの準備をさせず手軽に遊びたい場合 | PC (Windows) | Webブラウザ (Chrome等) または PC | ホストが発行したURLを友達がブラウザで開くだけで即参加 |
| **③ 同一PCでの2画面テスト** | 友達と繋ぐ前に自分1人でマルチ動作を確認したい場合 | PC (Windows) 1台 | - | Godotエディタから2画面同時起動してローカル接続 |

# 🛠️ 【事前準備】

本番の手順に入る前に、必要な準備を完了させてください。

## 1. ホスト側（あなた）の事前準備

### 1-1. Godot Engine 4.x の用意
- 本プロジェクト（`Tag_Game`）を Godot 4.x（4.3 / 4.4 / 4.7 互換）で開ける状態にしておきます。

### 1-2. Cloudflare Tunnel (`cloudflared`) のインストール（※インターネット経由で遊ぶ場合必須）
ポート開放なしで外部の友達と安全に通信するために使用します。
1. Windowsの PowerShell を起動します。
2. 次のコマンドを実行してインストールします：
   ```powershell
   winget install --id Cloudflare.cloudflared
   ```
3. インストール完了後、PowerShellウィンドウを開き直します（PATHを反映させるため）。

### 1-3. Steamクライアントの起動 & ログイン（※① Steamマッチングを使う場合）
1. PCで Steam クライアントを起動し、ログインしておきます。
2. プロジェクトのルート直下に `steam_appid.txt`（内容: `480`）が存在することを確認します（リポジトリ標準で同梱済み）。
3. `addons/godotsteam/win64/` に GodotSteam の DLL ファイルが存在することを確認します（リポジトリ標準で同梱済み）。

---

## 2. 友達（参加者）側の事前準備

友達が選択するプレイスタイルに合わせて準備してもらいます。

### パターンA：① Steam P2Pマッチングで参加する場合（PC同士）
1. Steam クライアントを起動し、自分のアカウントでログインしておく。
2. ホストと同じプロジェクト（または配布されたゲームビルド + `steam_appid.txt`）を準備し、Godotで起動できる状態にしておく。

### パターンB：② 参加リンクでWebブラウザから参加する場合（最も簡単）
- **特別な事前インストールは不要です。**
- Google Chrome, Microsoft Edge, Firefox などの最新ブラウザを用意するだけでOKです。

# 🚀 【手順】マッチング・動作確認の流れ

---

## 方式①：Steam P2Pマッチメイキングで遊ぶ手順（PC同士）

Steamのロビー機能を使って部屋を探して合流します。

### ステップ 1【ホスト側：部屋の作成】
1. Steam クライアントが起動していることを確認します。
2. Godotエディタでプロジェクトを開き、**F5キー**（または右上の再生ボタン）でゲームを起動します。
3. タイトル画面で **「PLAY」** ボタンをクリックします。
4. 「ルームマッチ」画面が開きます：
   - **自動作成（クイック）**: **「おまかせマッチ」** を押すと、空き部屋がなければ自動的に自分のレート帯で部屋が作成されます。
   - **手動作成**: **「+ 部屋を作成」** ボタンを押してタブを切り替え、部屋名を入力して **「この設定で作成」** を押します。
5. 部屋が作成されると自動的にゲーム待機画面（3Dマップ + 中央にロビーパネル）に移行します。
   - ※裏で自動的に通信トンネル（PowerShell画面）が立ち上がりますが、そのままにしておいてください。

### ステップ 2【友達側：ロビーへの参加】
1. Steam クライアントが起動していることを確認します。
2. ゲームを起動し、タイトル画面で **「PLAY」** ボタンをクリックします。
3. ロビー一覧が表示されます（更新されない場合は **「更新」** をクリック）。
4. ホストが作成した部屋を探し、**「参加」** ボタンをクリックします（または **「おまかせマッチ」** をクリック）。
5. 接続が完了すると、友達側の画面もホストと同じ3Dマップのゲーム待機画面に遷移します。

### ステップ 3【役割選択とゲーム開始】
1. **役割の立候補/指名**:
   - 逃走者になりたいプレイヤーはキーボードの **`R`** キーを押して立候補します（またはロビーパネルの「逃走者に立候補」ボタン）。
   - ホストは **`Tab`** キーを押して逃走者を指名・順送りできます。
   - 誰一人立候補しない場合は、開始時にランダムで1名が逃走者（Runner）になります。
2. **ラウンド開始**:
   - ホストがキーボードの **`Enter`** キー（またはロビーパネルの「ラウンド開始」）を押します。
3. ゲームが開始されます！

## 方式②：参加リンクを友達に送って遊ぶ手順（Web/PC）

ホストが発行したURLを友達に共有するだけの最も手軽な方法です。

### ステップ 1【ホスト側：サーバー起動とリンク取得】
1. Godotエディタでゲームを起動（F5）します。
2. タイトル画面で **「PLAY」** をクリックし、**「DirectConnect」** タブを選択します。
3. **「直結ホスト開始」** ボタンをクリックします。
4. ゲーム待機画面に移行すると同時に、裏で別ウィンドウ（PowerShell）が自動起動し、Cloudflare Tunnel が確立されます。
5. PowerShell ウィンドウに以下のような緑色の参加リンクが表示され、自動的にクリップボードにコピーされます：
   ```text
   ===================== 参加リンク =====================
    https://oekklab-source.github.io/Tag_game/?s=xxxx.trycloudflare.com
   ======================================================
   （クリップボードにコピー済み）
   ```
6. コピーされたURLを Discord や LINE 等で友達に送信します。

### ステップ 2【友達側：リンクから参加】
1. 友達は受け取ったURL（`https://...?s=xxxx.trycloudflare.com`）をブラウザで開きます。
2. Web版ゲームが読み込まれ、自動的にホストのゲームへ接続されます。
3. 待機画面に友達のキャラクターが出現します。

### ステップ 3【役割選択とゲーム開始】
1. 逃走者役を `R` キーで決めるか、未定のままにします。
2. ホストが **`Enter`** キーを押してラウンドを開始します。

---

## 方式③：1台のPCで2画面起動して事前テストする手順

友達と遊ぶ前に、自分のPCだけで2プレイヤー分の動作を確認する方法です。

1. Godotエディタのメニューバーから **「デバッグ」 > 「実行インスタンスをカスタマイズ...」** を開きます。
2. **「複数インスタンスを実行」** を有効にし、インスタンス数を **`2`** に設定して「OK」を押します。
3. **F5キー** を押して実行すると、ウィンドウが2つ立ち上がります。
4. **ウィンドウ 1（ホスト）**:
   - 「PLAY」 → 「DirectConnect」タブ → **「直結ホスト開始」** をクリック。
5. **ウィンドウ 2（クライアント）**:
   - 「PLAY」 → 「DirectConnect」タブ → アドレス欄が `127.0.0.1` になっていることを確認して **「アドレス指定で参加」** をクリック。
6. 両方のウィンドウが同じゲーム空間に接続されたら、ホスト側ウィンドウで **Enter** を押してゲーム開始を確認します。

# 🎮 【基本操作 & ルール・動作確認ポイント】

## 基本操作表

| キー / 操作 | 動作 | 備考 |
| :--- | :--- | :--- |
| **W / A / S / D** | 前後左右に移動 | - |
| **マウス移動** | カメラ視点操作 | 画面クリックでマウス固定、`Esc` で解放 |
| **Shift（長押し）** | ダッシュ | スタミナを消費（速度1.5倍） |
| **Space** | ダイブ（前方に低く跳び込む） | 鬼の捕獲や逃走の緊急回避。着地時に少し隙あり |
| **E / マウス右クリック** | アイテム使用 | ？ブロックから取得したアイテム（ロケット/バナナ/壁）を使用 |
| **R** | 逃走者に立候補 / 取消 | ※待機中（準備中）のみ |
| **Tab** | 逃走者の順送り指名 | ※ホストのみ・待機中のみ |
| **Enter** | ラウンド開始 | ※ホストのみ・待機中のみ |

## 動作確認チェックリスト

マッチング成功後、以下の項目が正しく機能しているか確認してください。

- [ ] **同期確認**: お互いの移動、視線方向、ジャンプ台・滑り台の動きがスムーズに相手画面に反映されているか。
- [ ] **非対称の索敵システム**:
  - **Runner（逃走者）**: 右上に全体マップが表示され、鬼の位置・距離・接近警告が見えているか。
  - **Hunter（鬼）**: Runnerが視界（48m以内・視界角100度・壁遮蔽なし）に入らない限り位置が見えないこと。誰か1人が目撃するとゾーン名（SPOTTED）が共有されるか。
- [ ] **ヘッドスタート**: 開始直後の8秒間、鬼は動けず逃走者だけが移動できるか。
- [ ] **ギミック動作**:
  - 土管ワープ：入ると対になる土管から射出されるか。
  - ジャンプ台：高台へ跳び上がれるか。
  - 滑り台：一方通行で勢いよく滑り降りられるか。
  - ？ブロック：触れるとアイテムが取得でき、`E` キーで使用できるか。
- [ ] **タッチ判定 & リザルト**:
  - 鬼が逃走者に接触すると「つかまえた！」と表示され鬼チームの勝利になるか。
  - 3分間逃げ切ると逃走者の勝利になるか。
  - 終了後、レート（Rating）の増減が表示され、待機画面に戻るか。

# ⚠️ 【トラブルシューティング・よくある落とし穴】

### Q1. 「ポート 9999 が既に使われています」と表示されてホストできない
- **原因**: 以前起動した Godot のゲームプロセスがバックグラウンドに残っています。
- **対処法**: タスクマネージャ（`Ctrl + Shift + Esc`）を開き、残っている「Godot Engine」プロセスを終了してから再起動してください。

### Q2. Steam初期化に失敗する（`Running in Offline / Fallback mode`）
- **原因**: Steam クライアントが起動していないか、ログインしていません。
- **対処法**: Steam を通常通り起動・ログインした状態でゲームを起動してください。またプロジェクト直下に `steam_appid.txt` があるか確認してください。

### Q3. Web版の友達が「接続中...」のまま入れない / エラーになる
- **原因1**: ホスト側の `cloudflared` が起動していない、またはトンネル確立前にリンクを開いた。
  - **対処**: PowerShell ウィンドウで緑色の参加リンクが表示されたことを確認してから友達に開いてもらってください。
- **原因2**: ホスト側と友達側のゲームバージョン（PROTOCOL_VERSION）が異なっている。
  - **対処**: GitHub Pages の Web ビルドが最新か確認し、友達にブラウザのスーパーリロード（`Ctrl + F5` または `Ctrl + Shift + R`）を試してもらってください。

### Q4. 部屋一覧に友達の部屋が表示されない
- **原因**: レート帯フィルタが厳しすぎるか、Steamのロビー取得タイミング。
- **対処**: 「すべて表示」に切り替えて「更新」を押すか、お互いに「おまかせマッチ」を押してください。
